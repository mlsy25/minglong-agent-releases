# 明隆云印 · 店端

### 自助打印 / 复印 / 扫描 的门店端程序

顾客在手机上下单、传文件，店里这台电脑负责收文件、排版、出纸，再把取件码发给顾客。插一张纸、扫一份文件，都能自己走完。

## 📥 下载与安装

**Windows 版**

1. 到 [Releases](https://github.com/mlsy25/minglong-agent-releases/releases/latest) 下载 `明隆云印店端_版本号_Setup.exe`，双击安装（默认装在 `D:\明隆云印店端`，可以改）。
2. 首次打开如果提示「Windows 已保护你的电脑」，点 **更多信息 → 仍要运行**（程序没有买代码签名证书，属于正常提示）。
3. 打开后在 **设置 · 设备绑定** 里填 8 位激活码，点「激活并绑定」，状态变成「已绑定」即可。
4. 在 **设置 · 打印与价格** 里选默认打印机，点「打印测试页」确认能出纸，再打开「收到文件即打印」开关。

**Releases 里两个文件的区别**

- `明隆云印店端_版本号_Setup.exe` —— **新装用这个**，完整安装程序。
- `MingLongAgent-版本号.zip` —— **自动更新用这个**，店端自己下载替换，不用人管。也有人在网盘传不动时用它手动覆盖升级。

## 🔄 自动更新怎么走

装好之后不需要再手动下载。店端自己会保持更新：

1. 每小时去本仓库的 Releases 看一眼有没有新版本。
2. 有的话**在后台悄悄下载好**，界面右下角变绿提示：「`x.x.x` 的更新包已经下好了，点「安装并重启」就换新」。
3. 老板点一下，程序退出、替换文件、自动重新打开，**不用重新登录、不用重新填激活码**。
4. 只升「比当前版本高的那一版最小的」，不跳版。店里机器旧一点也能一版一版稳稳跟上来。

**不会偷偷换**：不点「安装并重启」，程序一直用当前这版，不会自己重启、不会自己改文件。

**设置和配置不会丢**：所有数据都在 `我的文档\mlsy\明隆云印店端\`，更新只替换程序文件，`config.json` 会被跳过。备份的时候把这个文件夹整个复制走就行。

## 💾 数据放在哪

全部在 **`我的文档\mlsy\明隆云印店端\`**（具体路径因电脑而异，安装后在设置页能看到完整路径）：

- `config.json` —— 店铺绑定、价格、打印机、FTP 等设置
- `incoming` —— 顾客刚传上来、还没入库的文件
- `library` —— 已入库的文件
- `scans` —— 扫描仪扫进来的扫描件
- `meta` / `scans-index.json` —— 文件台账
- `print-log.csv` / `ftp-log.csv` —— 打印记录、收件记录
- `updates` —— 自动更新下载的包

换电脑或重装：把这个文件夹拷过去，装好程序再指到同一个路径，设置和历史都在。

## ❓ 常见问题

**杀毒软件报毒，程序被删了**

误报。程序没有买代码签名证书，加上自动更新会替换自己的程序文件，容易被当成可疑程序。

- Windows 安全中心：病毒和威胁防护 › 保护历史记录 › 找到本程序 › **还原 / 允许**；
- 再到 病毒和威胁防护设置 › 排除项 › **添加文件夹**，选程序所在文件夹；
- 360 / 火绒同样在恢复区还原，再把程序文件夹加进信任区。

建议把程序装在单独文件夹（如 `D:\明隆云印店端`），不要放桌面或盘根目录，方便加排除项。

**店里收不到顾客传的文件**

店端要开着「扫描仪 FTP 收件」或保持在线，顾客才能传。检查：

1. 设置页 · FTP 扫描服务是否显示「运行中 · 端口 21」；
2. 防火墙是否放行了本程序（端口 21 与 50000-50100）；
3. 顾客那边看店铺状态是不是「在线」，休息中不接新单。

**扫描件收不到 / 扫描仪连不上**

扫描仪/打印机上的「扫描到 FTP」地址要填设置页显示的那个局域网地址和端口 21，多数机器不支持密码，用户名随便填。

**打印不出来**

1. 设置页点「打印测试页」，能出纸说明打印链路没问题；
2. 不能出纸：检查默认打印机选对了没、纸盒有没有纸；
3. 有任务但一直排队：看「打印队列」页的状态提示，报错原因写在那一行。

**提示「找不到这个更新仓库」**

更新地址没配对或网络不通。正常情况下不用管；如果换过仓库地址，在设置页「版本与更新」里把「用户名/仓库名」填对。

**换电脑了怎么办**

装好程序，在设置页把「存储路径」指到拷贝过来的旧数据文件夹，再重新激活绑定即可。
